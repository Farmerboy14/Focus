# Focus

A home screen for Android that runs your day in blocks. Each block switches the phone to a preset,
so only the apps that belong in that part of the day will open. Includes Time with God, the King James
Bible with word search, and a locked prayer journal.

Install: download `release/Focus.apk` on the phone. After that, Focus updates itself from this repo.
